## To Execute

### 1. Set the API key

Choose **one** of these:

```bash

export GEMINI_API_KEY="your-key-here"
export DATAMATE_LLM_BACKEND="gemini"

# Option B: Anthropic Claude
export ANTHROPIC_API_KEY="your-key-here"
export DATAMATE_LLM_BACKEND="anthropic"

# Option C: Local Ollama (offline)

export OLLAMA_MODEL="qwen2.5-coder:14b"
export DATAMATE_LLM_BACKEND="ollama"

# Option D: Groq
export GROQ_API_KEY="your-key-here"
export DATAMATE_LLM_BACKEND="groq"
```

## Resume Behavior

The script automatically:
1. Loads existing sub_sonnet.jsonl
2. Extracts all done question IDs
3. Skips them in processing
4. **Appends** new answers (never overwrites)

If interrupted mid-run, just re-run the same command—it will resume from where it left off.

## Expected Results

With a working backend, expect:
- ~70-80% questions answered (number, percent, string types)
- ~15-25% unanswerable (insufficient data)
- ~5-10% abstain (if LLM fails on a question)

## Logs

Per-question details are NOT logged by this script (unlike Docker inference.py).  
For debugging, check:
- `_code` field in sub_sonnet.jsonl (code generated by LLM)
- `_err` field if present (execution error)

## After Processing

Once complete:
1. Check answer count with: `grep '"type": "abstain"' sub_sonnet.jsonl | wc -l`
2. Verify new IDs were added: `wc -l sub_sonnet.jsonl` (should increase by ~100)
3. Optionally merge with other models if running parallel pipelines
